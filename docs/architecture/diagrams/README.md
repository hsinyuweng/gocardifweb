# 架構圖與示意圖

把網頁架構圖、畫面示意圖放在這個資料夾（PNG、JPG、PDF、SVG 都可以）。

## 命名方式

`YYYY-MM-DD_內容.副檔名`，例如 `2026-10-20_網頁架構.png`。

- 日期放在最前面，新舊版本才會依時間排序，舊版不用刪除。
- 檔名可以用中文。
