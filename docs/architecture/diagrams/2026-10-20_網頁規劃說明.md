# 網頁規劃說明（2026-10-20，使用者提供）

> 這是 `2026-10-20_網頁規劃說明.pdf` 與 `2026-10-20_網頁架構.pdf` 的文字版，內容照原文抄錄，方便搜尋與閱讀。以 PDF 為準。
> 這份是**規劃**，不是網頁現況。現況見 `../overview.md`。

## 架構圖

```
首頁
├── 新聞與法規監控
├── 市場脈動
├── 追蹤清單  ◀───────────────────────────────┐
└── 競品研究                                    │
      ↓                                         │
   （顏）當國外有新商品時                          │
      ├── （翁）國內市場趨勢適用                    │
      ├── （塗）國內發生率暨獲利調查                 │
      └── （孫）國內法規適用                       │
            ↓                                   │
         總結與統整 ── 若主管看完報告，覺得該競品不錯值得參考、
                       認為法國巴黎人壽在台灣引進類似商品有市場和前景 ┘
```

追蹤清單：保留候選商品，可以依據幾個指標，協助排序這些候選商品，於台灣發行此商品的可行性獲利性市場飽和度等等。

使用者對於可行性、獲利性等等的重視程度可能不同，權重讓使用者自己調整，讓使用者在候選清單頁面可以拖動權重滑桿、即時看排序變化。（例如保守型主管可能更看重法規可行性，積極拓展型主管可能更看重市場飽和度缺口）

## 首頁四區塊——功能與點進去看到什麼

### 1. 新聞與法規監控

首頁：只列標題、分類標籤、時間，一行一則，版面簡潔。

點進去：
- 上方是六個頁籤：全部｜商品與通路動態｜市場與總經情勢｜監理法規｜理賠與消保｜客群經營與品牌公關
- 每個頁籤下是該領域最新項目，新聞與法規混排、依時間排序，每條前面有 [新聞] 或 [法規] 小標籤，附來源與時間
- 另有一個可疊加的篩選開關：「只看影響追蹤清單商品」
- 法規類項目展開後，會列出它影響了追蹤清單裡的哪些商品

### 2. 市場脈動

首頁：顯示 1 到 2 個成長動能指標，數值加迷你趨勢線。

點進去：完整儀表板，五組指標，頂部有一句自動生成的「本月焦點」摘要：
- 成長動能：新契約保費年增率、各險別（外幣、投資型、傳統、健康）占比與成長率
- 定價環境：10 年期公債殖利率趨勢、IFRS17／TW-ICS 關鍵時程
- 通路結構：業務員／銀行保險／數位通路占比變化，含數位通路滲透率
- 健康度：全行業解約率與繼續率趨勢
- 品牌聲量：同業品牌與商品關鍵字的搜尋熱度比較

資料由獨立的排程 skill 更新，不經過 LLM 深度研究。

### 3. 追蹤清單

首頁：顯示目前被加入追蹤的候選商品（商品名稱、來源市場、目前綜合分數）。

點進去：
- 所有候選商品依綜合分數排序
- 排序維度：可行性、獲利性、市場飽和度，另有可選的第四維度「品牌／通路契合度」（預設權重為 0，不影響預設排序）
- 每個維度一支權重滑桿，拖動後排序即時重算
- 分數旁可展開看計算明細
- 點商品可回到完整研究報告，也可移出清單

這是全站唯一需要逐項深度比較的畫面。

### 4. 競品研究

首頁：顯示顏在背景已研究完成、尚未審閱的商品報告（商品名稱、來源市場、完成時間）。

點進去：完整報告，是總結與統整合併翁、塗、孫三方研究的成品，內容已就緒，不用等待：
- 總覽：一段話結論加三個燈號（市場需求／獲利可行性／法規適用）
- 市場趨勢（翁）、發生率與定價研究（塗）、法規適用性（孫）
- 每筆 finding 可展開看原始來源與可信度標籤
- 若翁的研究剛好蒐集到競品的品牌定位或異業合作資訊，執行摘要多帶一句話
- 頁面底部有「加入追蹤清單」按鈕

## 完整網站使用者流程

### 背景流程（使用者看不到）

1. 顏偵測到國外新商品，用內部初篩分數（證據密度、來源可信度、時效性、搜尋熱度）判斷是否值得深入研究
2. 值得研究的，先比對台灣是否已有相似商品
3. 無相似商品，才交給三個模組平行分析：國內市場趨勢適用（翁）、國內發生率暨獲利調查（塗）、國內法規適用（孫）
4. 三模組完成後，總結與統整合併成完整報告，存進系統
5. 整個過程自動完成，不需要使用者觸發或等待

### 使用者主線

6. 打開首頁，「競品研究」區塊顯示新完成的報告
7. 點進去閱讀完整報告
8. 主管看完，認為法國巴黎人壽在台灣引進類似商品有市場和前景，按「加入追蹤清單」
9. 首頁「追蹤清單」區塊更新，顯示新加入的商品
10. 進入追蹤清單頁，依個人重視的面向拖動權重滑桿，看排序變化，作為是否正式推進的決策參考

### 隨時可用的情報瀏覽（不依賴主線）

11. 「新聞與法規監控」依六大領域持續更新，商品開發、行銷、公關背景的使用者都能在對應頁籤找到自己要的內容
12. 「市場脈動」由獨立 skill 排程更新，每天都有新數據，不用等顏的研究週期
13. 若新法規影響追蹤清單裡的商品，該法規項目會標示出受影響的商品，使用者可打開篩選開關只看這類項目，並回頭複核該商品
