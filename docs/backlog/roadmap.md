# 未來架構與分階段計畫

> 依據：`architecture/diagrams/2026-10-20_網頁規劃說明.md`（頁面與功能）、`architecture/diagrams/2026-10-27_視覺改版規劃.md`（視覺、版面、市場脈動分頁）。狀態：方向與順序已確認（2026-10-20）；各階段開始前仍要確認介面文字。完成的階段從本檔刪除，現況寫進 `architecture/overview.md` 與 `decisions/`。

## 1. 目標架構

| 路徑 | 頁面 | 內容 |
|---|---|---|
| `#/` | 首頁 | 四區塊：新聞與法規監控、市場脈動、追蹤清單、競品研究 |
| `#/news?tab=&affects=1` | 新聞與法規監控 | 6 頁籤；新聞、法規混排依時間；[新聞]／[法規] 標籤；「只看可能相關追蹤清單商品」開關；法規展開列出可能相關與同險種的追蹤商品 |
| `#/market`、`#/market/:tab` | 市場脈動 | 「總覽」分頁（結論＋4 數字＋四組小圖）＋各組分頁：成長動能、定價環境、通路結構、品牌與競爭、健康度（有資料才出現）；每頁第一個畫面放重點，往下是細節（視覺改版） |
| `#/watchlist` | 追蹤清單 | 候選商品依綜合分數排序；權重滑桿（法規可行性、市場規模、市場成長、品牌／通路契合度預設 0）即時重排；展開計算明細；看報告、移出 |
| `#/research` | 競品研究（全部報告） | 原案件總覽表格；未審閱標示 |
| `#/report/:id` | 報告 | 閱讀路徑＋頂部列「加入追蹤清單」 |
| `#/tasks`、`#/guide` | 我的待辦、使用說明 | 保留 |

導覽列：首頁、新聞與法規監控、市場脈動、追蹤清單、競品研究、我的待辦、使用說明；規劃中：跨部門審查。
