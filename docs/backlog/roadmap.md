## 3. 分階段

每階段開始前列介面文字表等「確認」；每個新頁都有麵包屑「首頁 / 頁名」並保留篩選（網址）。

2. **追蹤清單改為候選商品**：存 report_id（舊「險種＋市場」清單直接停用，已決定）；報告頁「加入追蹤清單／已加入・移出」；首頁卡顯示名稱、來源市場、綜合分數；`#/watchlist` 滑桿、即時排序、計算明細。分數先用三面向燈號換算（可行性＝法規、獲利性＝發生率暨獲利、市場飽和度＝市場需求），畫面註明「暫用燈號換算」（已決定）。
3. **新聞與法規監控**：定 feed 新格式（`domain` 6 領域、`kind` news／regulation）並更新 api-contract 與示意資料；首頁卡改一行一則；`#/news` 頁籤、影響篩選、法規展開受影響商品。
4. **市場脈動**：定 market-pulse 新格式（`group`、`focus_summary`、占比、時程）；首頁 1–2 指標；`#/market` 五組儀表板。
5. **接後端**：真實 feed、market-pulse；數值分數取代燈號換算；finding 來源與可信度、品牌定位；多人共用的審閱狀態。

## 4. 要請後端提供（補進後端需求文件）

- 報告：各維度數值分數與說明（可行性、獲利性、市場飽和度、品牌／通路契合度）、每筆 finding 的來源與可信度、品牌定位／異業合作一句、完成時間。
- feed：`domain`（6 領域）、`kind`（新聞／法規）、法規影響的 `related_report_ids`。
- market-pulse：指標分組、本月焦點摘要、占比與時程資料；由獨立排程每日更新。
- 後端需求文件（Claude Doc，使用者擁有）：https://claude.ai/code/artifact/91c6050f-8416-40cc-b0f1-76e3f79b7c62
